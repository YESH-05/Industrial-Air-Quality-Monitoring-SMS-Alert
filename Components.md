# Components

- ESP32 WROOM development board — controller and Wi-Fi connectivity
- MQ-2 — smoke/combustible-gas sensing module
- MQ-135 — air-quality-related gas sensing module
- BME280 — temperature, humidity and pressure
- 16x2 I2C LCD — local display
- Wi-Fi network — internet connectivity for SMS API
- Twilio account and sender number — SMS delivery service
- Suitable power supply, wiring and voltage conditioning
